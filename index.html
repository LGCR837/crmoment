CRMoment

一个轻量的社交动态分享平台。基于 PHP + MySQL，简单、快速、可自托管。

✨ 进入 Web 版 了解更多
⚡

极简部署

上传即用，仅需 PHP + MySQL。无需 Node.js、无需构建工具、无需复杂配置。

🔓

公开浏览

未登录也可浏览动态和评论。登录后可发布内容、点赞、评论，体验完整社交。

📦

本地存储

头像和动态图片存储于服务器本地，不依赖第三方云存储服务。

🛠 技术栈

PHP 8+ MySQL PDO Session Auth Material Web RESTful API
